# Golampi — Intérprete y Compilador

Proyecto académico desarrollado en PHP utilizando ANTLR4.
Implementa un intérprete para un lenguaje inspirado en Go y un compilador
capaz de generar código ARM64.

## Tecnologías

- PHP
- Programación Orientada a Objetos
- ANTLR4
- ARM64 / AArch64
- HTML / CSS / Bootstrap

## Características

- Análisis léxico
- Análisis sintáctico
- Análisis semántico
- Tabla de símbolos
- Manejo de ámbitos
- Estructuras de control
- Funciones
- Manejo de errores
- Interpretación de código
- Generación de código ARM64
